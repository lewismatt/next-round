## Visual system

The newspaper character comes from composition rather than a texture layer:

- An oversized serif masthead, a small edition line and an italic strapline.
- Double masthead/footer rules; strong section rules and fine column dividers.
- A numbered, three-column games index before current matches and invitations. Phone layouts use a single reading column.
- Monochrome vector puzzle illustrations, readable serif copy, and small sans-serif utility labels.
- Square, flat controls: filled ink for the main action, outlined ink for puzzle and resume actions. No colored navigation or illustration accents.
- A square crossword grid with solid blocked cells and printed Across/Down lists, rather than rounded clue cards.

The palettes share semantic tokens in `packages/ui/src/styles/globals.css`; application and crossword styles consume those tokens. Destructive actions retain semantic red. The previous slate/amber accents and generated paper overlay are removed, including the unused runtime texture asset. The older files in `concepts/` remain historical references, not the current fidelity target.

Native Georgia/Times/serif fallbacks provide the masthead and reading face. Existing locally bundled UI fonts and shadcn Button remain; no dependency or package pins change.

## Behavior preserved

Appearance still applies before first paint, follows the OS until explicitly selected, persists locally, and synchronizes across tabs. The existing Start, create, resume, join, accept, sign-out, History, Admin and game commands remain unchanged. Choosing a game in the index preselects it in the existing creation dialog; it does not silently create or start a match.

Guest Home remains limited to invited games without a catalog or Start control; Admin navigation remains role-dependent. Phone navigation and safe-area clearance remain. The skip link now focuses the actual main landmark rather than an empty div, and dialog dismissal restores the originating control.

The crossword layout now stacks board and clues through 1100px to avoid a collapsed tablet board beside the platform sidebar. A high-specificity native-control reset was also corrected so primary game buttons keep contrasting labels in both themes.
