## Bounded fixes in this review

- **Error privacy:** `server.ts` logged arbitrary unhandled errors, including
  driver `detail` and nested causes that may contain private rows or guesses.
  Log a fixed error code with the existing request correlation ID. A regression
  checks both the log call and response; raw messages/stacks are excluded.
- **Case-insensitive retries:** PostgreSQL returns UUIDs in lowercase, but
  `MatchService.act` compared the stored match ID with the route's original case.
  Normalize the route ID before receipt comparison and response construction.
  Extend the real PostgreSQL retry test with uppercase route/command UUIDs and
  assertions that state, events and receipt counts stay unchanged.
- **Documentation:** distinguish intended architecture from implemented routes;
  correct session-secret rotation guidance (current cookies are unsigned opaque
  tokens); preserve partial acceptance instead of treating merges as full passes.
