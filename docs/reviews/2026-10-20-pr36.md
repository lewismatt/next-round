## Findings

| ID | Priority | Finding and concrete follow-up |
| --- | --- | --- |
| BL-051 | P2 | `apps/api/src/routes/health.ts` always declares a heartbeat stale after 30 seconds, while `apps/worker/src/worker.ts` emits it at the configurable reconciliation interval. With the supported `LIVE_RECONCILE_INTERVAL_MS=60000`, a healthy worker is labeled stale before its next heartbeat is due. A probe of the actual route handler with a 45-second-old heartbeat returned `stale`; the interval validator accepts 60000. Decouple heartbeat cadence from reconciliation or persist cadence and derive the stale threshold per worker. Verify a healthy nondefault cadence and a genuinely missed heartbeat. |
| BL-052 | P2 | The first half of the outstanding-cap test in `apps/api/src/invitation-budgets.integration.test.ts` seeds 30 outstanding registrations, then mints 20 guests. Both the 50-outstanding and 20-per-hour budgets bind before the assertions, so the guest and link 429s can come entirely from the hourly budget. The later rotation section clears rate buckets and proves the member outstanding path, but not guest/link outstanding enforcement. Clear rate buckets before the three over-outstanding assertions; verify each rejects without consuming a mint or creating a row. This is an evidence gap, not an observed production enforcement bypass. |
| BL-053 | P3 | Worker IDs are fresh UUIDs. Only graceful shutdown deletes a heartbeat; crashed-worker rows have no pruning or query bound and the health endpoint returns all rows. Repeated crashes leave a growing permanent list of stale workers. Add a documented bounded retention policy while preserving a useful crash diagnostic window. The catch comment saying the row ages out does not match any implemented cleanup. |
| BL-054 | P3 | PR #36's BL-050 row has `P2` in the State column, five cells instead of six, and its resolution in the Issue column. The burn-down says 49 Fixed while the PR body says 50 Fixed. Normalize the row to the documented schema and derive counts from valid state cells; retain the distinction between branch resolutions and integrated fixes. |
